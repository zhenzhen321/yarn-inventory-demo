| 目录 | 内容 | 解决的问题 |
| --- | --- | --- |
| [01-需求分析](01-需求分析/需求与目标.md) | 项目背景、目标、范围、功能点 F1-F16、关键决策 | 需求是什么？做哪些、不做什么？ |

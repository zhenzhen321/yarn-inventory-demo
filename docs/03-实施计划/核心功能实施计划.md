# 核心功能实施计划

> 依据：《需求与目标.md》与两份设计文档。每个任务遵循 TDD：先写失败测试 → 实现 → 测试通过 → 提交一次。

## 里程碑

| 里程碑 | 内容 | 验收标准 |
| --- | --- | --- |
| M1 基础框架 | Next.js 脚手架、Prisma 数据模型、登录与会话 | 可登录，中间件保护 /app 与 /api |
| M2 档案管理 | 纱线、变体、仓库、往来单位 CRUD | 页面可增删改查，删除有引用保护 |
| M3 库存引擎 | 买入、卖出、调拨、盘库 | 库存增减正确，不足拦截，单测覆盖 |
| M4 结算与报表 | 资金结算、库存金额、毛利、订单查询、Excel 导出 | 超结拦截，导出文件可打开 |
| M5 加工费流程 | 送加工、完工核算、成品批次、加工收回、工厂付款 | 未核算原料不可出厂；已核算成品可流转；欠款正确 |
| M6 安全与验收 | 限速、CSRF、审计日志、撤回、e2e | e2e 全部通过，测试数据可清理 |

## 任务拆分（示例）

| 任务 | 文件 | TDD 步骤 | 验证 | 提交信息 |
| --- | --- | --- | --- | --- |
| T1 会话工具 | `src/lib/session.ts`、`tests/session.test.ts` | 先写 sign/verify 失败测试 | `npx vitest run tests/session.test.ts` | `feat: add jwt session sign and verify with tests` |
| T2 登录接口 | `src/app/api/auth/login/route.ts`、中间件 | 先写登录与限速失败测试 | 同上 + e2e 登录用例 | `feat: add password login with jwt session and middleware` |
| T3 买入引擎 | `src/services/inventory.ts`、`tests/inventory.test.ts` | 先写「买入后库存增加、批次生成」失败测试 | `npm test` | `feat: implement purchase inventory engine with tests` |
| T4 卖出引擎 | 同上 | 先写「库存不足拦截、扣减正确」失败测试 | `npm test` | `feat: implement sale inventory engine with stock checks` |
| T5 调拨/盘库 | 同上 | 先写「总量不变、盘盈盘亏」失败测试 | `npm test` | `feat: implement transfer and stocktake engine with tests` |
| T6 结算服务 | `src/services/settlement.ts`、`tests/settlement.test.ts` | 先写「超结拦截、进度计算」失败测试 | `npm test` | `feat: implement settlement service with tests` |
| T7 报表与导出 | `src/services/reports.ts`、`tests/reports.test.ts` | 先写「金额/毛利计算」失败测试 | `npm test` | `feat: implement inventory valuation and flow report` |
| T8 加工费 | `src/services/inventory.ts`、`tests/processing-fee.test.ts` | 先写「未结算拦截、成本结转」失败测试 | `npm test` | `feat: add processing fee fields and settlement` |
| T9 撤回 | `src/services/revert.ts`、`tests/revert.test.ts` | 先写「撤回后库存回滚」失败测试 | `npm test` | `feat: revert records with inventory rollback` |

## 每任务收尾检查

1. `npx tsc --noEmit` 无错误
2. 相关测试通过
3. 提交一次，英文短消息（见上表）

## 全量验收

```bash
npm test                 # 全部单元测试
npm run build            # 生产构建
node scripts/e2e.mjs     # 端到端（需服务运行）
node scripts/cleanup-e2e.js  # 清理 E2E 测试数据
```

# 测试与验收

## 1. 测试策略

| 层级 | 工具/方式 | 覆盖内容 |
| --- | --- | --- |
| 单元测试 | Vitest（`tests/*.test.ts`） | 金额精度、会话、库存引擎、结算、报表、校验、限速、表达式、撤回、加工费、删除保护 |
| 类型检查 | `npx tsc --noEmit` | 全量 TypeScript 类型 |
| 构建 | `npm run build` | 生产构建通过 |
| 端到端 | `scripts/e2e.mjs` | 真实 HTTP 全流程验收 |

## 2. 单元测试清单

- `money.test.ts`：金额计算、四舍五入、单位换算
- `session.test.ts`：JWT 签发/验证/过期
- `inventory.test.ts`：买入入库、卖出扣减、库存不足拦截、调拨总量不变、盘盈盘亏
- `settlement.test.ts`：未结/部分/已结进度、超结拦截、折让聚合
- `processing-fee.test.ts`：加工费结算、成本结转、未结算出库拦截、部分结算
- `revert.test.ts`：撤回买入/卖出/结算后库存与账目回滚
- `reports.test.ts`：库存金额、毛利估算、订单查询
- `validation.test.ts`：请求参数校验
- `rate-limit.test.ts`：登录限速锁定
- `expression.test.ts`：重量表达式（如 `12*25`）计算
- `order-query.test.ts`、`orders.test.ts`、`deletion.test.ts`、`factory-fee.test.ts`：订单查询、记录展示、删除保护、工厂欠款

## 3. e2e 覆盖（`scripts/e2e.mjs`）

自包含、可重复运行：登录 → 建测试数据 → 买入（自动建变体/批次）→ 卖出（扣库存）→ 调拨 → 送加工 → 加工费结算（改规格/重量）→ 加工收回 → 盘库清零归档 → 结算与超结拦截 → 折让 → 撤回权限 → 报表/日志页面渲染 → 9 类 Excel 导出。

运行方式：

```bash
node scripts/e2e.mjs                     # 默认 localhost:3000
E2E_BASE_URL=http://localhost:3100 node scripts/e2e.mjs
node scripts/cleanup-e2e.js              # 清理带 E2E 前缀的测试数据
```

## 4. 验收标准

1. 克隆仓库后按 README 快速开始可一键跑通（建库 → 种子 → 启动 → 登录）。
2. 所有页面在桌面与手机宽度下可用。
3. 库存、结算、加工费金额计算与业务规则一致（单测覆盖）。
4. 错误路径有拦截（库存不足、超结、未结算加工费出库、越权撤回）。
5. e2e 全部通过且测试数据可清理，不污染演示数据。

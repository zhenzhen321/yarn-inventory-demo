## 3. e2e 覆盖（`scripts/e2e.mjs`）

隔离启动器使用 `prisma/e2e.db`、`127.0.0.1:3100` 和独立构建目录；运行前后比较 `prisma/dev.db` SHA-256，结束后清理带 E2E 前缀的数据。流程覆盖登录、Idempotency-Key 采购重试、批次销售/调拨、加工费、撤回、报表/日志、Excel 导出，以及两批投入两批产出加工和同一幂等键重放。

运行方式：

```bash
npm run test:e2e                         # 自动迁移 e2e.db、构建、启动 3100、运行并清理
# 禁止直接执行 node scripts/e2e.mjs；启动器会拒绝非隔离环境
```

## 4. 验收标准

1. 克隆仓库后按 README 快速开始可一键跑通（建库 → 种子 → 启动 → 登录）。
2. 所有页面在桌面与手机宽度下可用。
3. 库存、结算、加工费金额计算与业务规则一致（单测覆盖）。
4. 错误路径有拦截（库存不足、重复扫码、并发修改、超结、未核算原料出厂、越权撤回）。
5. 相同供应商批号的不同采购保持独立内部批次，销售成本来自实际分配批次。
6. 加工成品可反查原料批次、投入成本、损耗和后续销售。
7. e2e 全部通过且测试数据可清理，不污染演示数据。

提交前可运行 `npm run check` 一次完成单元测试、类型检查和生产构建。

## 5. 家庭点选界面验收

浏览器验收可在隔离服务运行时设置 UI_VERIFY_MODULES=1，再由启动器追加手机/桌面布局、快捷点选、大字模式、未保存提醒、加工分步往返和多投入多产出页面检查。未配置时仍执行完整业务 HTTP 流程。

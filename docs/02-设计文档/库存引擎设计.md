# 库存引擎设计

> 对应需求：F2-F8、F10、F14-F16。本文档定义库存的唯一数据入口；批次模型详见 [批次溯源与扫码出库设计](批次溯源与扫码出库设计.md)。

## 1. 目标

所有库存变化（买入、卖出、调拨、盘库、撤回）必须经过唯一服务层，保证：

- 任何一笔业务要么完整生效、要么完全回滚（事务）。
- 库存不足、未核算加工原料出库、并发重复扣减等非法操作在写入前被拦截。
- 成本与运费按重量比例精确分摊，可追溯。
- 每次变化同时更新分地点余额并追加不可变库存流水。

## 2. 核心数据模型

```
Yarn → YarnVariant → Batch（供应商批号，可重复使用）
PurchaseItem → InventoryLot（内部批次，唯一来源/成本身份）
InventoryLot → Inventory（按地点保存当前余额）
InventoryLot → StockMovement（采购/调拨/加工/销售/盘点/冲销流水）
SaleItem → SaleAllocation → InventoryLot（实际销售批次）
ProcessingInput → ProcessingJob → ProcessingOutput → 新 InventoryLot
```

关键点：`Batch` 是外部供应商批号，`InventoryLot` 才是唯一内部货源批次；`Inventory` 只负责当前位置余额，`StockMovement` 负责不可变历史。卖出时按实际内部批次比例扣减成本/运费，调拨保持批次不变。

## 3. 业务规则

| 规则 | 说明 |
| --- | --- |
| 单号自动生成 | PO/SO/TO/ST 前缀 + 日期 + 序号，序号取现存最大单号 +1，避免撤回后撞号 |
| 变体自动创建 | 买入新色号时自动创建变体，录入无需预先建档 |
| 内部批次自动创建 | 每条采购明细生成唯一 `LOT-日期-序号`；供应商批号相同也不合并 |
| 一批一码 | 内部批次生成随机扫码令牌；标签二维码不保存成本 |
| 库存不足拦截 | 卖出/调拨前校验 `row.weight >= 请求重量`，不足直接报错 |
| 并发出库拦截 | 余额更新同时校验版本号，失败时要求刷新重试 |
| 成本分摊 | 卖出/调拨时 `movedCost = cost * weight / row.weight`，最后保留两位小数 |
| 运费分摊 | 买入运费按明细重量比例分摊；调拨运费按本次移动重量分摊后累加 |
| 盘库调整 | 实盘数直接覆盖重量，成本/运费按新重量等比例缩放，差值记入盘盈盘亏 |
| 加工厂出库边界 | 未核算原料禁止出厂；已核算成品不受加工费付款状态限制 |
| 加工形成新批次 | 投入原料批次被消耗，实际产出始终形成带父子血缘的新成品批次 |
| 撤回不删除 | 保留原采购/销售单，追加反向流水恢复批次余额 |
| 清零归档 | 盘库清零后标记 `archived`，从常规库存列表隐藏，保留历史单据关联 |

## 4. 服务接口（唯一入口）

`src/services/inventory.ts` 对外暴露：

- `createPurchase(db, input)`：买入入库
- `createSale(db, input)`：卖出出库
- `createTransfer(db, input)`：调拨（含送加工）
- `createStocktake(db, input)`：盘库
- `settleProcessingFee(db, inventoryId, input)`：加工费结算
- `createProcessingReturn(db, input)`：加工收回
- `archiveZeroInventory(db, warehouseId)`：清零库存归档
- `src/services/lots.ts`：内部批次号、扫码令牌、余额增减、成本分摊、流水和状态刷新

所有函数内部使用 `prisma.$transaction`，HTTP 层只做参数校验（zod）与鉴权，不直接操作库存。

## 5. 待确认点与决策

| # | 问题 | 决策 |
| --- | --- | --- |
| Q1 | 未填批次时怎么处理？ | 自动生成批次号，保证可追溯 |
| Q2 | 运费计入结算金额吗？ | 不计入应收应付，只计入库存成本与毛利 |
| Q3 | 盘库差异要自动生成调整单吗？ | 记录在盘库单明细中，差异=实盘-账面，不额外生成单据 |
| Q4 | 加工后支数/色号变化如何处理？ | 完工时允许变更，始终创建新的成品内部批次并结转成本 |
| Q5 | 供应商批号相同是否合并？ | 不合并；每条采购明细都有独立内部批次与成本层 |
| Q6 | 加工费未付款能否销售成品？ | 可以；完工核算与后续付款分离 |
